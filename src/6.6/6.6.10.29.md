# Release notes Shopware 6.6.10.29

## Abstract

This patch release includes 6 closed issues with fixes for international media file names, media URL encoding, GARAN mail labels, and release preparation. It also introduces broader system activity logging for users, integrations, plugins, and apps, while ensuring releases cannot be published without the matching changelog entry.

## System requirements

* tested on PHP 8.2 and 8.4
* tested on MySQL 8 and MariaDB 11

## Improvements

(No notable improvements in this patch release)

## Fixed bugs

* Fixed non-ASCII characters being corrupted or stripped from uploaded media file names ([#20988](https://github.com/shopware/shopware/pull/20988))
* Fixed media URLs with non-ASCII characters and already-encoded paths being encoded incorrectly ([#20989](https://github.com/shopware/shopware/pull/20989))
* Fixed GARAN mail labels not being passed correctly to Twig templates ([#21196](https://github.com/shopware/shopware/pull/21196))
* Added system activity logging for user and integration creation and plugin/app lifecycle actions ([#21199](https://github.com/shopware/shopware/pull/21199))
* Fixed release publishing so a missing changelog entry prevents an incomplete release from being published ([#20563](https://github.com/shopware/shopware/pull/20563))
