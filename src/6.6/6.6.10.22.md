# Release notes Shopware 6.6.10.22

## Abstract

Shopware 6.6.10.22 is a patch release. This release focuses on security hardening and ACL (Access Control List) enforcement across multiple admin endpoints, including template rendering, media actions, SEO routes, queue statistics and message queues ensuring that all administrative actions now properly respect user privileges. On the bug-fix side, several cart and checkout issues are addressed, particularly around promotion calculations, delivery discount pricing, and promotion composition values. Additional fixes improve SEO URL management (allowing editing of write-protected URLs), variant bulk editing for sales channel visibility, and category external links without requiring a protocol. The release also includes dependency updates (dompdf) and improvements to app permission enforcement for the Extension SDK.

## System requirements

* tested on PHP 8.2 and 8.4
* tested on MySQL 8 and MariaDB 11
