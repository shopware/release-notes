# Release notes Shopware 6.6.10.31

## Abstract

This release includes 27 closed issues, delivering corrections across checkout and payment processing, product streams, API security, email privacy, and Administration functionality. It also improves storefront accessibility, expands support for GARAN manufacturer guarantee information, and brings several refinements to the development and testing infrastructure.

## System requirements

* tested on PHP 8.2 and 8.4
* tested on MySQL 8 and MariaDB 11

## Improvements

(No notable improvements in this patch release)

## Fixed bugs

- Prevented API term searches from exposing values in fields that are not accessible to the requesting API source ([#22114](https://github.com/shopware/shopware/pull/22114))
- Corrected order bulk editing so payment status changes apply to the current transaction instead of an outdated failed transaction ([#22102](https://github.com/shopware/shopware/pull/22102))
- Fixed product stream updates after category assignments so products are correctly added to or removed from dynamic product groups ([#21071](https://github.com/shopware/shopware/pull/21071))
- Improved email log privacy by excluding sensitive content from password recovery and double opt-in email logs ([#22353](https://github.com/shopware/shopware/pull/22353))
- Improved storefront accessibility by allowing long words in product descriptions and property values to wrap correctly on narrow screens and at enlarged text sizes ([#21436](https://github.com/shopware/shopware/pull/21436))

See all fixed bugs in this release: https://github.com/shopware/shopware/milestone/59?closed=1
