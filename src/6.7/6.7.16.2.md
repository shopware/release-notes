# Release notes Shopware 6.7.16.2

## Abstract

Shopware 6.7.16.2 is a patch release that fixes four bugs.

This release ships 4 closed issues, resolving a conflict between Twig and Shopware dependencies that blocked Composer installations. It also updates the release documentation and incorporates the 6.7.16.1 security release into the release branch.

## System requirements

* tested on PHP 8.2, 8.4 and 8.5
* tested on MySQL 8, MySQL 9.7, MariaDB 11 and MariaDB 12

## Improvements

(No notable improvements in this patch release)

## Fixed bugs

* Fixed a Composer dependency conflict that prevented Shopware from being installed ([#23369](https://github.com/shopware/shopware/pull/23369)).
