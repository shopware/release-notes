# Release notes Shopware 6.7.12.2

## Abstract

Shopware 6.7.12.2 is a patch release that fixes two bugs.

This release ships 2 closed issues, focused on dependency security and configuration compatibility. It updates the dompdf library used for document rendering to a patched version and ensures that the new cache compression configuration keys remain backward compatible with existing setups.

## System requirements

* tested on PHP 8.2, 8.4 and 8.5
* tested on MySQL 8 and MariaDB 11

## Improvements

(No notable improvements in this patch release)

## Fixed bugs

* Updated the PDF rendering library (dompdf) to version 3.1.6, which resolves two published security advisories affecting document generation ([#18596](https://github.com/shopware/shopware/pull/18596))
* Restored backward compatibility for cache compression settings, so shops that still rely on the previous configuration keys keep working when only the new keys are set ([#18196](https://github.com/shopware/shopware/pull/18196))
