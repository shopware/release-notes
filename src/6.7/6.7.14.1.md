# Release notes Shopware 6.7.14.1

## Abstract

Shopware 6.7.14.1 is a **security release. Please update as soon as possible!** If you cannot update for some reason it is strongly recommended to make use of the [Security plugin](https://store.shopware.com/en/swag136939272659f/shopware-6-security-plugin.html).

## System requirements

* tested on PHP 8.2, 8.4 and 8.5
* tested on MySQL 8, MySQL 9.7, MariaDB 11 and MariaDB 12

## Improvements

(No notable improvements in this patch release)
