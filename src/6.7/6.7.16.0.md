# Release notes Shopware 6.7.16.0

## Abstract

This release includes 396 closed issues, bringing corrections across the Administration, Storefront, checkout, product management, pricing, order processing, and sales channel configuration. It also introduces improvements to MCP integration and AI-assisted workflows, new Store API capabilities for reordering orders, spatial scenes in the Storefront, and expanded guarantee management.

## System requirements

* tested on PHP 8.2, 8.4 and 8.5
* tested on MySQL 8, MySQL 9.7, MariaDB 11 and MariaDB 12

## Improvements

- **More flexible product management:** Digital products now support external file assignments and configurable order quantities. Product variants and filtered listings also behave more consistently.
- **Improved order and checkout handling:** Order recalculations preserve the original addresses and payment amounts. Reordering products and checking payment and shipping availability for existing orders are also supported.
- **Better pricing transparency:** Discount percentages now use the lowest price of the last 30 days as their reference.
- **Expanded guarantee information:** GARAN labels and guarantee terms are available in more places, including product pages, order confirmations and checkout.
- **Administration improvements:** System configuration can be organized into tabs, order line items are paginated, and product and category editing gets clearer guidance.
- **More flexible Store API:** New extension points, improved session handling and additional checkout and reorder capabilities make it easier to build custom storefronts.
- **Improved MCP integration:** MCP gets better result handling, more reliable notifications, configurable access and improved support for large tool responses.
- **More options for apps and extensions:** Apps can define SEO URLs for storefront pages, while extensions gain additional customization and integration points.

For more detailled information, please visit https://github.com/shopware/shopware/releases/tag/v6.7.16.0.

## Fixed bugs

* Fixed incorrect tax calculations when recalculating orders, ensuring the original order's shipping address and country are retained even if the customer's default address has changed ([#20741](https://github.com/shopware/shopware/issues/20741)).
* Fixed delivery promotions so that inapplicable discounts no longer prevent other eligible fixed-price shipping discounts from being applied ([#20169](https://github.com/shopware/shopware/issues/20169)).
* Fixed storefront product search so that product names and search terms containing characters such as `<` are indexed and searchable correctly ([#20637](https://github.com/shopware/shopware/issues/20637)).
* Fixed theme configuration inheritance so that changes to a parent theme are correctly propagated to all descendant themes and their assigned sales channels ([#21641](https://github.com/shopware/shopware/issues/21641)).
* Corrected storefront discount calculations to use the lowest price of the last 30 days as the reference price, ensuring accurate discount percentages and price-reduction labels ([#18738](https://github.com/shopware/shopware/issues/18738)).

See all fixed bugs in this release: https://github.com/shopware/shopware/milestone/53?closed=1
